## Implemented behavior

- `ProviderTokenBudget` retains canonical-selector-local positive calibration, missing-usage preservation/reset, saturating calibrated estimates, selected input/model output limits and integer five-percent headroom. Existing domain `ContextCadence`, `ContextCompactionPolicy`, `ContextSnapshot`, `ContextSize`, `TokenEstimator` and `RetainedAgentBudget` are reused, not reimplemented.
- `CompactionPlanner` estimates the complete actual request: UTF-16 text, tool definitions/call arguments, selected-provider image costs and fixed overhead. Context reporting uses total window; triggering/fit use selected input capacity and captured alias/global overrides. Checkpoint selection, incomplete-prefix backup and base-watermark no-progress rules preserve causal groups.
- `Compactor` renders the actual catalog's summary instructions/prefix and oversized-group notice. It performs actual provider-session calls, awaited retry observation, exact completion/barrier behavior, bounded complete-group chunking, recursive empty-summary half-folding, real blob persistence and actual returned-path notice-fit checks. First-pass spills occur in source order, including earlier committed spill effects before a later rejection. Chunking rechecks actual preceding summaries and permits a late eligible substitution only once.
- The executor returns summary + fixed status + intact retained groups and verifies the final complete selected-model input limit. Summarized history is not deleted from the authoritative database. Retained content, tool IDs/results, image references and provider-native replay fields are cloned intact.
- `ContextController` awaits T44 epoch sampling, materializes actual `AgentHistoryView` effective groups and checkpoint metadata, observes/refits status, commits the real snapshot/status/watermark, resets calibration only after successful persistence, reloads `AgentConversation`, acknowledges cadence and awaits publication. It emits started/finished/failed lifecycle events, including failure after a terminal-publication error. Public forced `compact` bypasses the trigger but returns unchanged for an unavailable input limit. Direct `compact_epoch` retains source's **unguarded** no-progress estimate-versus-input-limit failure, even for zero/negative capacity.
- `ensure_epoch` and `inject_status` support source pre-promotion ordering. Status-fit estimates include actual next-promotion materialized input parts. Child initial status is injected once; root status uses actual mode/version consumption. `StatusInjection::RefreshSelection` returns ownership to the caller for full profile/model/security refresh before retrying.
- Cadence checkpoints are restored from actual history, coalesced across reopen, rebased on model/window/history changes and acknowledged after compaction/reminder insertion. A candidate reminder crossing the trigger is discarded in favor of actual compaction. Final-provider-request and tool-restoration markers use real projection state and restore once.
- `provider_message` converts actual storage materialization without reading image bytes during estimation. Real image artifact persistence/materialization, provider-request loading, retained images and reopen are exercised. Literal source image-size rows and OpenAI calculator boundaries (56/150 images, 97,048/229,376 image tokens, bounded eight-image chunking) use the actual native calculator.

## Invocation and ownership contract

`Compactor::new(settings, profiles, templates)` renders execution template text; the settings' rendered-text fields remain useful to the independent planner but are overridden by the real catalog for execution. `compact` accepts actual resolved selection, target, `PlanningInput`, **mutable** real `CompactionGroupBlobStore`, shared caller-owned `ProviderSessions`, awaited `RetryObserver` and cancellation.

`ContextController::new(compactor, history, blobs, templates)` owns context-epoch state, calibration and cadence. `EpochInput` borrows the existing `parrot_storage::conversation::AgentConversation`, selection/tools, T44 `SystemPrompt`, provider sessions and bound status/event adapters. There is no duplicate conversation model.

T46 must await/join each controller/executor future, not drop it to cancel. The caller owns provider-pool begin/close/drain lifetime, complete turn/profile/security selection, tool advertisement/availability decisions and the single oversized-request retry. Normal ordering is awaited `ensure_epoch` → `inject_status` (refresh full selection if requested) → caller skills/tool restoration/promotion → `prepare_epoch`; oversized retry calls `compact_epoch` once. Explicit user compaction calls `compact`. Estimation, final-request and tool-restoration methods are also exposed without duplicating persistence in the drain.

`ContextError::InvalidOperation` identifies only the four explicit source invalid-operation sites (rendered/final input limit, duplicate snapshot and no safe boundary); `Argument` identifies blank tool-call IDs. Their display text is unchanged. Generic template/adapter `Operation` remains opaque/unexpected; consumers must not infer a diagnostic kind by parsing its message or classify every `Operation` as an invalid operation.

`ContextStatus` is bound by the actual status owner to its agent/profile/selection; it must evaluate the supplied actual-history estimator when fitting. `ContextEvents` distinguishes:

1. `emit(Event, cancellation)`: caller's actual emitter persists the new lifecycle event and publishes after commit.
2. `publish_committed(Committed<Event>, cancellation)`: the controller supplies an attestation **only after** `append_compaction_status(...).await` returned true and the source's reload/cadence steps completed. The adapter forwards the supplied receipt to the real committed publisher. False/error paths never attest.
3. `publish(Event, cancellation)`: retained publication after projection-only status/reminder/final/restoration effects. Those source operations deliberately do **not** record an Event row. Retained is not durable/replayable; adapters must not invent a commit, append an extra event, downgrade to transient, or infer the route from notice kind.

The owning `RetainedAgentBudget` reservation transitions are literal source-tested here; user-session/registry reservation lifetimes remain T48/T53 composition, not a second budget service in this controller. Summary calls use the supplied actual provider/session decorators; turn usage recording remains the actual T46/provider/statistics owner. No second output accounting is introduced.
