
# Git-ethics
You may use worktree to prevent conflict between parallel worker where reasonable. Put the worktree into the current directory such as in .worktrees/something. The current directory may be on a different drive than the home directory.
# Github
In the PR and commit message, mention that it is AI generated, mention the agent and model used. For a PR, also mention the cumulative session statistics, which are the models, tokens, costs, etc.
