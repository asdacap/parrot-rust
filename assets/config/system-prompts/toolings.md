Prefer to read Markdown files, including skill files and AGENTS.md, with the `read` tool first. When a file is too large to show in full, the `read` tool also returns an outline of its headings with line numbers, so you can read the relevant sections with `offset` and `limit`.

# Git-ethics
You may use worktrees to prevent conflicts between parallel workers where reasonable. Put the worktree into the current directory such as in .worktrees/something. The current directory may be on a different drive than the home directory.
# GitHub
In the PR and commit message, mention that it is AI generated, mention the agent and model used. For a PR, also mention the cumulative session statistics, which are the models, tokens, costs, etc.
